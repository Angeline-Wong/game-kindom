# 紫宸纪前朝玩法需求

## 文档边界

本文件依赖 [通用设定](通用设定.md)，定义前朝一级地图、朝会、奏折、官员、司法与前朝场景。后宫及皇嗣规则见 [后宫玩法](后宫玩法.md)。

## 前朝地图与场景

一级地图包含太和殿、乾清门、养心殿、军机处、御书房、文华殿、演武场、宗人府、内务府、会同馆、午门。门牌是唯一点击目标，不设置覆盖建筑的大热区。二级场景对应朝会、批折、军情、经筵、演武、宗室、宫廷产业、使团与典礼等玩法。

## 朝会与奏折

每日举行朝会，可设宰相或太子辅政。重大议题每日最多一个，必须经历多方发言、辩论、皇帝裁决或容后再议；容后议题隔日继续直至裁决。普通议题数量由皇帝选择，允许持续开朝。皇帝可震怒、要求官员或皇子作答、交办调查或暂缓裁断。

奏折区分紧急度与真实性。呈报者可信度、情报来源与调查结果影响可见可信度；未知信息不得直接展示真相。朝仪、迟到、缺席、失礼和站班影响官员评价、威严、派系与事件。

## 官员体系与任免

官员来源包括科举、荐举、捐纳、军功、地方政绩与特殊事件；历史名臣作为有成本的特殊人才。官员采用正一品至从九品的九品十八级体系，品级与实权分开计算。

中央机构包括内阁、军机处、吏户礼兵刑工六部、都察院、大理寺、通政司、翰林院、国子监、鸿胪寺、宗人府和内务府。任命、调任、升品、降品、降职、革职、致仕和差事必须展示职位、能力、资历、忠诚、派系、继任或署理安排及政治代价。

## 官员处分与天牢

官员可被申饬、罚俸、停职待勘、降品、降职、革职、夺职、流放建议或移交天牢。降品由皇帝从低于当前的具体品阶中选择目标。天牢仅适用于重罪嫌疑或定罪，分拘押待审、定罪监禁、释放/平反/大赦；必须保留案由、证据可信度、审理机关、期限、连坐与赦免字段。

未经审理的长期监禁、极刑或抄家将提高冤案、御史弹劾、派系对抗和民望风险。宗室涉案由宗人府会同刑部或大理寺处理。

## 内务府与前后宫联动

内务府分账管理宫廷采购、修缮、宫人和皇家产业；皇帝可调拨，但每次调拨写入账目与后续预算。后宫外戚、妃嫔晋封、皇嗣与宫斗案件可牵动任命、工程、军权与派系，不得把后宫与前朝做成互不影响的两套系统。
