# 紫宸纪前朝玩法需求

## 文档边界

本文件依赖 [通用设定](通用设定.md)，定义前朝一级地图、朝会、奏折、官员、司法与前朝场景。后宫及皇嗣规则见 [后宫玩法](后宫玩法.md)。

## 前朝地图与场景

一级地图包含太和殿、乾清门、养心殿、军机处、御书房、文华殿、演武场、宗人府、内务府、会同馆、午门。门牌是唯一点击目标，不设置覆盖建筑的大热区。二级场景对应朝会、批折、军情、经筵、演武、宗室、宫廷产业、使团与典礼等玩法。

## 朝会与奏折

每日举行朝会，可设宰相或太子辅政。重大议题每日最多一个，必须经历多方发言、辩论、皇帝裁决或容后再议；容后议题隔日继续直至裁决。普通议题数量由皇帝选择，允许持续开朝。皇帝可震怒、要求官员或皇子作答、交办调查或暂缓裁断。

奏折区分紧急度与真实性。呈报者可信度、情报来源与调查结果影响可见可信度；未知信息不得直接展示真相。朝仪、迟到、缺席、失礼和站班影响官员评价、威严、派系与事件。

## 官员体系与任免

官员来源包括科举、荐举、捐纳、军功、地方政绩与特殊事件；历史名臣作为有成本的特殊人才。官员采用正一品至从九品的九品十八级体系，品级与实权分开计算。

中央机构包括内阁、军机处、吏户礼兵刑工六部、都察院、大理寺、通政司、翰林院、国子监、鸿胪寺、宗人府和内务府。任命、调任、升品、降品、降职、革职、致仕和差事必须展示职位、能力、资历、忠诚、派系、继任或署理安排及政治代价。

## 官员处分与天牢

官员可被申饬、罚俸、停职待勘、降品、降职、革职、夺职、流放建议或移交天牢。降品由皇帝从低于当前的具体品阶中选择目标。天牢仅适用于重罪嫌疑或定罪，分拘押待审、定罪监禁、释放/平反/大赦；必须保留案由、证据可信度、审理机关、期限、连坐与赦免字段。

官员操作列固定为：调任、改品、奖励、问责。调任可上调、平调或降调；改品可升可降。奖励可选御赐墨宝、赏银百两、赏金百两和国库珍宝，国库珍宝必须跳转国库选择。问责可选严厉呵斥、罚俸一月、罚俸一年、抄家落狱、流放百里、株连九族。

未经审理的长期监禁、极刑或抄家将提高冤案、御史弹劾、派系对抗和民望风险。宗室涉案由宗人府会同刑部或大理寺处理。

## 内务府与前后宫联动

内务府分账管理宫廷采购、修缮、宫人和皇家产业；皇帝可调拨，但每次调拨写入账目与后续预算。后宫外戚、妃嫔晋封、皇嗣与宫斗案件可牵动任命、工程、军权与派系，不得把后宫与前朝做成互不影响的两套系统。
## 本轮交互补充

- 大臣操作固定为调任、改品、奖励、问责；调任与改品均允许升降，分别使用官员任职调整与官员品阶调整界面。
- 奖励为御赐墨宝、赏银百两、赏金百两、国库珍宝；问责为严厉呵斥、罚俸一月、罚俸一年、抄家落狱、流放百里、株连九族。

## 羁押、释放与臣子换代

- 抄家落狱必须实际改为在押状态并迁入羁押场景，不得继续上朝、调任、领差、随机移动或出现在普通臣子候选中；在押人物仅可探望、赐死、释放。
- 探望调整人物关系并写入履历；赐死将人物改为死亡；释放恢复自由，但官品、官职、财产和案件结论是否恢复必须分别裁定。
- 在职臣子死亡或被永久移出官场后形成真实缺额。补授的继任者从 500 名臣子姓名库中生成，本朝已用姓名不得再次出现，且忠诚、派系、财富和关系重新计算。

## 朝会与科举实现规范（第二版）

### 乾清门每日朝会

- 乾清门为每日常朝唯一入口；太和殿不承载每日常朝，保留殿试、传胪及重大典礼。路线固定为：乾清门 → 开始朝会 → 朝堂百官总览 → 选择六部名牌 → 官员出列奏事 → 皇帝三选一裁决 → 数值反馈 → 下一奏折/换人 → 退朝结算。
- 朝堂总览以吏、户、礼、兵、刑、工六部名牌呈现，名牌显示待议奏折数量、当前呈报官员和到班状态；无待议事项的名牌不可点击。死亡、羁押、休养或缺席官员不得出列。
- 选择名牌后先展示“有本启奏”过场，再展开奏折。奏折页使用录屏式人物立绘、姓名牌、摘要和可信度，不直接展示未揭示真相。
- 每项议题保存类别、摘要、呈报人、隐藏可信度、发言记录、裁决、状态和历史日期。每项奏折提供三个有差异的四字裁决选项，至少包含从严、从轻或调查留中路径。
- 裁决后立即展示“朱批已下”反馈页，列出文治、武备、政务、民生、帝王心情、国库、官员忠诚与朝堂氛围等实际变化；数值修改、人物属性、财务和历史记录必须原子写入本地存档。
- “下一奏折”继续当前朝会的下一项议题；“换人”返回朝堂总览重新选择六部。两者都不重复生成当日议题，也不重置已处理结果。
- 朝班点卯记录到班、迟到、缺席、失仪和原因。调查或留中将议题标为留中并在次日置于议程首位；退朝时所有未处理议题统一留中。
- 同日再次进入乾清门只显示“继续朝议”或“今日散朝”，不重复创建会话。追问、调查、裁决和退朝均消耗游戏内时间，处理事项、所用时间、参与人物和数值变化写入人物履历与朝会历史。

### 既有场景科举链

不新增宫殿，科举按既有场景拆分：

1. 文华殿：奉旨开科、选择本科侧重与主考官、御览乡试名录、举行会试、阅卷取贡士、传胪后授官和查看科举档案。
2. 御书房：会试取定六名贡士后，由皇帝从策问题库亲定殿试题目。
3. 太和殿：举行殿试，皇帝按选择顺序钦定状元、榜眼、探花；随后举行金殿传胪。
4. 文华殿：传胪礼成后为十二名进士授官，人物正式进入臣子库和君臣关系网。

- 科举默认三年一科；本届完成前不可重复开科，完成后三个在位年方可再次举行。
- 开科从 500 名臣子姓名库抽取十二名未使用姓名；本朝已经使用的姓名不得重复。
- 候选人保存年龄、籍贯、出身、经义、策论、品行、野心、会试成绩、殿试成绩与最终甲第。
- 会试按经义、策论、品行与稳定随机种子计算，取前六名贡士参加殿试。
- 状元授翰林院修撰，榜眼、探花授翰林院编修，其余依名次授庶吉士或候补知县；授官同步生成六项官员核心属性、关系、人物履历和科举历史。
- 科举状态、候选人、题目、名次和授官结果全部进入本地存档，刷新与切换场景不得丢失。
