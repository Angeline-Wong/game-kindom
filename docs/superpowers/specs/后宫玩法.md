# 紫宸纪后宫玩法需求

## 文档边界

本文件依赖 [通用设定](通用设定.md)，定义后宫地图、十二宫、位分、人物关系、皇嗣、宫斗与处分。前朝官员与司法主体规则见 [前朝玩法](前朝玩法.md)。

## 地图与宫殿结构

后宫一级地图包括御花园、乾清宫、交泰殿、坤宁宫、西六宫（储秀、翊坤、长春、咸福、启祥、永寿）、东六宫（景仁、承乾、钟粹、永和、景阳、延禧）、慈宁宫、毓庆宫、御膳房、寿康宫、撷芳殿、上书房、太医院与冷宫。冷宫位于外宫右侧，慈宁宫与寿康宫形成相邻长辈宫区。

十二宫进入后均采用宫门、主殿、东侧殿、西侧殿、后殿、庭院与回廊结构。后殿 V1 不作为点击入口；主殿、东侧殿、西侧殿和庭院可承载人物与事件。宫殿可改名、升级，升级必须改变地图外观与功能。

## 位分、待遇与迁宫

正式位分及上限：皇后 1、皇贵妃 1、贵妃 2、妃 4、嫔 6、贵人/常在/答应/官女子不设固定上限。嫔位及以上为主位娘娘，通常可居主殿；低位妃嫔通常居东西配殿。无主位时最高位可临时居主殿，但不获得正式宫权和仪仗。

迁宫必须两步选择“宫殿 → 主殿/东侧殿/西侧殿”，只显示符合位分且空置的房间。新主位迁入时原临时居主殿者必须获得迁居安排。位分决定月例、宫人、膳食、服饰、仪仗、礼仪、侍寝、生育与宫权；摄六宫事可授予二至三名符合资格主位辅助皇后。

## 人物关系、宠幸与宫斗

妃嫔拥有才情、礼仪、容貌、健康、野心、争宠等公开或情报估值，并维护嫉妒、安全感、恩宠、关系、外戚、宫人和隐藏计划。宠幸存在敬事房翻牌与宫殿直访两种入口；进入妃嫔宫殿后可直接安排当夜留宿，无需再翻牌，但仍受时间、状态、禁足、疾病、年龄和日程限制。

宫斗由观察、调查、证据与处置构成。调查可跟踪、收买宫人、查出入、查敬事房/太医院记录、搜查、询问、安插眼线和设诱饵。传闻、目击、记录、物证、口供和证据链可信度不同，错误处置会产生冤罚、黑化、皇嗣怨恨与外戚反弹。

## 妃嫔处分、冷宫与复位

妃嫔可被申饬、扣月例、禁足、降位、褫夺封号、撤摄六宫事、迁出主殿、收回宫权和打入冷宫。降位必须由皇帝选择低于当前的目标位分，重新计算待遇、仪仗、主位资格和居所。打入冷宫不是删除人物：停止常规侍寝与宫务，但保留调查、探视、复审、特赦、复位和子女安置。复位不自动恢复旧主殿或宫权。

妃嫔操作列固定为：临幸、闲聊、赏赐、搬迁、改位、问责。改位同时允许上调和下调目标位分；上调成功后颁布对应人物与目标位分的圣旨，下调直接结算处置结果。赏赐可选御赐墨宝、赏银百两、赏金百两、国库珍宝和封号；封号允许一至两字且不可与现有有效封号重复，国库珍宝进入国库选择。问责可选严厉呵斥、罚俸一月、罚俸一年、褫夺封号、打入冷宫、赐自尽。临幸只使用帘幕过场与次日结算，闲聊只进入对话选择。

妃嫔产后进入三个月休养期，休养期结束自动恢复“安好”；人物仍显示在固定居所内。有孕妃嫔不可临幸，只能陪伴；休养、病中、禁足、冷宫、在押等状态均不得进入翻牌候选。

## 皇嗣与宗室

皇嗣记录生母、养母/养父、排行、健康、天资、性格、学识、武艺、威望、婚姻、母族和继承倾向。可安排抚养、名师、伴读、课程、婚嫁、封爵、开府、入朝与立储。课程至少支持上午、下午、晚间与教师选择。

皇嗣和宗室处分包括训诫、禁足、停课/停差、削爵、褫夺封号、幽禁、圈禁及移交天牢。重罚后必须重算储位、婚约、子女、师傅、母族、支持者与夺嫡事件。无有效储君时，皇子与公主均可参与夺嫡；女嗣继位进入女帝朝并切换为男后宫规则。

皇子与公主操作列固定为：教育、鼓励、封爵、赏赐、问责。封爵必须选择爵位并允许输入自定义封号；赏赐选项与妃嫔一致。问责可选严厉呵斥、禁足、削爵、打入宗人府、赐死；不再设置“安排老师”独立操作，老师由教育流程内指定。

### 皇嗣成年与婚配

- 皇子、公主年满十五岁视为成年，可进入婚配流程；未成年、死亡、受押、已有婚配或已有未结婚配事务者不可再次选择。
- 撷芳殿右上设置“皇子列表”和“皇子婚配”两个场景按钮（内部规则同时覆盖公主）。无符合条件的成年皇嗣时，由内侍提示“当前没有年满十五岁且尚未婚配的皇嗣”，提示关闭后留在撷芳殿。毓庆宫不再承载这两个入口。
- 毓庆宫右上设置“选立太子”按钮，皇子、公主均可成为候选；选择并确认后播放对应册立圣旨，用印结算后储君身份更新为太子或皇太女，住所与场景迁至毓庆宫。已有储君时入口改为“改立太子”；改立后旧储君恢复册立前身份与居所，新储君迁入毓庆宫并写入履历。
- 婚配先选择皇嗣，再选择“礼部挑选”“婚配大臣”“举宴相看”之一。成功婚配必须建立配偶关系、补全人物关系网并写入双方履历。
- 礼部挑选：礼部呈选四名候选。每名候选显示家族品阶、父辈官职、嫡庶、子/女、姓名、魅力和谋略，例如“正一品太傅嫡女傅静姝，魅力 90、谋略 90”。皇帝选定后择吉完婚。
- 婚配大臣：从在朝且存活的臣子中亲选。臣子已有原配时弹出二次选择“换一位”或“刺死原配”；换人不改变状态，刺死会结算原配死亡、移除旧配偶关系并记录历史，再完成皇室婚配。
- 举宴相看：颁令后十四日在御花园举办。宴会当日白天，该皇嗣与其生母固定在御花园，可通过人物互动询问相看感受；宴会次日由内侍回禀二人属意人选，皇帝选择同意或不同意。同意则完婚，不同意则本次婚配作罢并允许重新筹办。
## 本轮交互补充

- 主位娘娘（嫔及以上）在“赏赐”中可获授“协理六宫”；同一存档最多三名妃嫔协理，已满时不可再授。
- 妃嫔“改位”允许升迁或降位，使用位份调整界面；升迁完成后颁布与该妃嫔姓名、目标位份一致的圣旨。
- 妃嫔“赏赐”包括御赐墨宝、赏银百两、赏金百两、国库珍宝；国库珍宝跳转国库多选。
- 妃嫔“问责”包括严厉呵斥、罚俸一月、罚俸一年、打入冷宫、赐自尽。

## 妃嫔日程、寻访与喜脉通知

- 妃嫔必须同时保存“固定居所”和“当前所在场景”。普通状态每日约有 25% 概率外出，有孕时约为 12%；当日决定外出后，白天只前往御花园、交泰殿或某一妃嫔宫室中的一个地点，不随上午/下午时辰继续换地点，酉时后回到固定居所。禁足、冷宫、天牢、病中和产后休养状态不得自由外出。
- 皇帝进入妃嫔固定居所而该妃嫔不在时，由宫女使用标准对话选项回禀实际去向。选项固定为“罢了”“回养心殿”“拜驾当前所在地”：罢了只关闭对话，另外两项分别导航到养心殿和妃嫔当前场景。
- 有喜通知固定使用内侍传言选项 UI。“大喜”使皇帝快乐增加；“前去关怀”导航到该妃嫔固定居所内部；“赏赐安胎”打开国库；“暂不声张”只关闭通知，不产生即时动作。
- 妃嫔在外期间不改变其固定居所。读档后应保留合法的当前所在场景，夜间日程再次结算时回宫。

## 交泰殿选秀

`交泰殿 → 颁令筹办 → 一月后殿选 → 撂牌子（入选）/赐花（落选） → 一月后入宫 → 皇后初拟位份与宫室 → 皇帝复核修改 → 正式入宫`

- 交泰殿右上宫务区增加“宫中选秀”入口。已有未完成选秀时不可重复筹办；完成后允许另办一届。
- 筹办后按照游戏时间等待一个月开放殿选。候选人必须有独立姓名、年龄、性格与六项妃嫔属性。
- 为避免术语歧义，按钮明确标注“撂牌子（入选）”与“赐花（落选）”。全部候选人完成决定后才进入下一阶段。
- 入选者再等待一个月入宫。皇后先为每人拟定初始位份、空置宫室和可选封号，默认不授封号；皇帝复核时可逐人更改。嫔位及以上必须分配空置主殿，低位分配东西侧殿，同一宫室不得重复分配。
- 御览确认后，入选者写入人物库、后宫名册、固定居所、当前场景、皇帝配偶关系和历史记录；此时才算正式入宫。

## 养心殿翻牌

`养心殿 → 召幸翻牌 → 绿头牌列表 → 选中妃嫔 → 传旨临幸 → 宠幸帘幕动画 → 次日卯时结算`

- 养心殿右上场景交互区增加四字按钮“召幸翻牌”，采用既定翻牌子界面，不再另造弹窗框架。
- 牌面实时读取人物库中的姓名、位份、封号和固定宫殿，按每页八人分页；关闭键和“再想想”只退出翻牌，不产生记录。
- 候选人只包含状态为“安好”的在册妃嫔。有孕、产后休养、抱病、禁足、冷宫、在押、死亡人物不得显示。
- 确认“传旨临幸”后关闭翻牌界面，立即进入宠幸帘幕动画；动画完成或跳过后关闭过场并登记当夜临幸计划，由次日卯时统一结算怀孕概率、关系、恩宠和履历。
- 在妃嫔本人宫殿内发起临幸仍属于直接留宿，不经过翻牌子。

## 长辈宫与强制拘禁

- 慈宁宫常驻皇太后，寿康宫常驻太妃。两类人物独立于在册妃嫔，不进入翻牌和妃子名册；人物操作为请安、闲聊、赏赐、探望，并维护与皇帝、皇后、宗室及母族的关系。
- “打入冷宫”必须实际将人物状态改为冷宫、当前位置改为冷宫，并保存原位分、封号和原居所。冷宫人物不得串门、翻牌、临幸、宫务或自动回原宫，只显示探望、刺死、恢复三项操作。
- 探望增加好感并写入履历；刺死将人物改为死亡并从可操作人物中移除；恢复必须由皇帝重新选择位分，并按新位分随机安排合法空置宫室。恢复不自动授回协理六宫等职权，但原有效封号继续保留。
- 妃嫔的封号与人物绑定，不与当前位分绑定。正常晋升、降位、生育晋升、剧情改位、冷宫复位均继承封号，只有“褫夺封号”或死亡才取消其展示。
- 皇嗣打入宗人府后固定在宗人府，不得学习、婚配、封爵或自由活动，只显示探望、赐死、释放；官员抄家落狱后同理固定在羁押场景。释放后恢复自由，原官职、爵位是否恢复由后续皇帝决定。
- 选秀入选者入宫一个月后，由皇后先拟定位份、封号和宫室。拟定完成后必须通过内侍对话邀请皇帝前往交泰殿复核；皇帝确认前不得正式写入后宫名册。
- 生育通知提及产妇时统一使用“位份 + 姓名”，例如“贵人顾清漪平安诞下皇子”；封号只用于人物名牌与正式册文，不替代该通知的位份信息。
