# 紫宸纪交互设计

## 1. 文档目的与状态

本文定义全游戏的交互入口、弹窗职责、操作路线、状态结算和反馈规则。它是前端实现、剧情配置、数值结算和验收的共同依据。

状态标记：`已实现` 指可操作原型；`部分实现` 指已具备界面或路径但结算未闭环；`待开发` 指规则已确认、尚未实现。

## 2. 统一交互总则

- 地图地点与人物名牌是热区；无文字方块覆盖原有门牌。
- 一级地图进入二级，二级进入三级；三级返回二级，二级返回一级，禁止越级返回。
- 人物头像栏最多显示四人，点击头像先触发必经剧情；无必经剧情时打开人物操作页。点击人物名牌才打开人物详情。
- 宫殿院落层只展示主殿、东侧殿、西侧殿和庭院入口，不直接展示常住妃嫔。人物位置精确到“宫殿 + 房间”；例如居住在翊坤宫西侧殿的贵人，只在进入翊坤宫西侧殿后出现。临时到访人物按事件位置显示。
- 所有影响资源、身份、职权、居所、自由、关系的操作遵循：`入口 → 条件提示 → 目标选择 → 确认 → 状态结算 → 场景/消息反馈 → 历史记录`。
- 点击遮罩、关闭按钮、返回按钮时，未确认的操作不结算；已确认操作只能结算一次。
- 正式任命、封爵、升位、升品使用圣旨；闲聊、临幸、普通赏赐、普通问责不使用圣旨。
- 所有操作按钮固定两个字；人物详情不在操作列重复出现“详情”或“履历”。

## 4. 反馈层级

### 4.1 即时反馈

- 按钮按下、禁用、选中、库存不足、编制已满均立即给出视觉状态。
- 成功的非正式操作使用消息提示，例如“顾清漪已获赏银百两”。
- 取消只关闭当前层，不改变人物、资源或时间。
- 操作完成后的结果弹窗必须明确写出“已执行”的动作、对象与即时影响；玩家点击右下角箭头或关闭按钮后，结果弹窗关闭并回到触发它的场景。关闭不撤销已确认操作。

### 4.1.1 内侍传言事件

内侍传言用于玩家未主动发起的异步通知：妃嫔怀孕、生育、疾病、请安、宫斗传闻、皇嗣成长、官员急报、灾情与外交消息等。

- 纯通知：`内侍传言 → 内容 → 关闭 → 写入历史`。例如“长春宫顾清漪已有喜脉，请陛下示下。”
- 带选项通知：`内侍传言 → 内容 → 选项 → 结果消息/后续场景 → 历史`。选项通常为 2 至 4 项，允许存在“暂不处理”或“稍后再议”。
- 怀孕通知示例：大喜、前去关怀、赏赐安胎物、暂不声张。不同选择影响宠爱、健康、胎儿风险、后宫嫉妒与事件链。
- 生育通知示例：前去探望、厚赏六宫、赐名/暂缓赐名、传太医。结果更新皇嗣、母体健康、宫廷声望与人物关系。
- 事件可被错过。超过有效时间后关闭或自动结算为默认结果，并在历史标记“未亲理”或“已错过”。
- 有明确抉择的内侍传言不能只显示关闭按钮；完成选择后才允许以结果箭头关闭。

### 4.2 正式结果

- 升位、升品、任命、封爵在确认后进入圣旨；用印后才写入状态和历史。
- 降位、贬斥、削爵、囚禁、流放等严重处分须二次确认；确认后显示结果消息并写入履历。
- 临幸在过场结束后仅登记当夜事件；怀孕、宠爱、健康、嫉妒及相关剧情在次日卯时统一结算。
- 结算触发的怀孕、生育等事件优先通过内侍传言弹出；若同一时刻有多条事件，按紧急度、主线、人物亲近度排序进入事件队列。

### 4.3 历史与延迟事件

- 每项已确认操作记录时间、地点、发起人、目标、选择、资源变化和后果。
- 延迟事件必须在历史中标记“待结算”，结算后追加结果，不覆盖原记录。
- 被错过的剧情记录为“已错过”，不得重新弹出。

## 5. 妃嫔交互路线

### 5.1 操作入口

妃嫔操作固定为：`临幸`、`闲聊`、`赏赐`、`搬迁`、`改位`、`问责`。

### 5.2 临幸

`妃嫔操作页 → 临幸 → 临幸过场 → 登记夜间事件 → 次日卯时结算 → 消息/剧情/历史`

- 前置：目标未处于冷宫、禁足、病危、天牢或外出状态；皇帝当夜未安排其他临幸。
- 不颁布圣旨。
- 结算因人物健康、宠爱、关系、避孕状态、事件和随机种子而异。
- 当前：过场与消息已接入；完整次日结算待开发。

### 5.3 闲聊

`妃嫔操作页 → 闲聊 → 对话选项框 → 选择回应 → 关系/心情变化 → 消息与历史`

- 选项可影响宠爱、信任、嫉妒、秘密、后续事件。
- 无可用剧情时显示简短日常对话，并记录轻量关系变化。

### 5.4 赏赐与协理六宫

`妃嫔操作页 → 赏赐 → 选择赏赐 → 确认 → 扣减资源/写入状态 → 消息与历史`

- 可选：御赐墨宝、赏银百两、赏金百两、国库珍宝。
- 国库珍宝进入国库多选，必须校验库存、数量、对象承载限制。
- 嫔位及以上主位可额外选择“协理六宫”。最多三名妃嫔同时协理；满额时禁用并显示原因。
- 协理六宫影响宫务效率、后宫秩序、皇后关系与派系权力，撤销、失宠、降位或死亡时自动解除。

### 5.5 搬迁

`妃嫔操作页 → 搬迁 → 空置居所列表 → 确认 → 更新居所/宫人/待遇 → 消息与历史`

- 目标只能为东西六宫中的空置主殿、东侧殿或西侧殿。
- 主殿优先要求嫔位及以上；无主位时，由该宫最高位妃嫔居住。
- 搬迁不改变位份；因位份变动导致居所不符时，系统给出限期迁居事件。

### 5.6 改位

`妃嫔操作页 → 改位滑轮 → 查看影响 → 二次确认 → 升位走圣旨/降位走处分结果 → 更新待遇与居所资格 → 历史`

- 可自主选择任意合法目标位份，受皇后 1、皇贵妃 1、贵妃 2、妃 4、嫔 6 编制限制。
- 升位触发册封圣旨；降位不使用册封圣旨，使用处分确认与结果消息。
- 改位同步更新俸禄、仪仗、宫权、居住资格、协理资格和人物关系。

### 5.7 问责

可选：严厉呵斥、罚俸一月、罚俸一年、打入冷宫、赐自尽。

- 严厉呵斥与罚俸：确认后即时结算。
- 打入冷宫：二次确认，迁至冷宫，移除宫权、仪仗和协理资格。
- 赐自尽：最高级操作，须展示不可逆警告；结算后人物死亡、关系和子女抚养触发后续事件。

## 6. 大臣交互路线

### 6.1 操作入口

大臣操作固定为：`调任`、`改品`、`奖励`、`问责`。

### 6.2 调任

`人物操作页 → 任职调整 → 选择新职/去向 → 查看权责影响 → 确认 → 圣旨或消息 → 历史`

- 允许升调、平调、降调、外放、罢职待勘。
- 任职合法性校验官职空缺、品阶、派系、回避关系与在押状态。
- 正式任命与升调使用圣旨；普通平调可使用任命告示。

### 6.3 改品

`人物操作页 → 品阶调整 → 选择目标品阶 → 查看待遇影响 → 确认 → 升品圣旨/降品结果 → 历史`

- 可升可降；升品使用圣旨，降品使用处分确认。
- 同步改变俸禄、可任官职、朝班位置、派系影响和忠诚波动。

### 6.4 奖励

可选：御赐墨宝、赏银百两、赏金百两、国库珍宝。

- 与妃嫔赏赐共用国库选择和库存结算。
- 可改变忠诚、声望、派系影响、已知财富与贪欲。

### 6.5 问责

可选：严厉呵斥、罚俸一月、罚俸一年、抄家落狱、流放百里、株连九族。

- 轻处分即时结算。
- 抄家落狱、流放、株连九族需要二次确认并触发朝局、派系、家族和民心后果。

## 7. 皇嗣交互路线

### 7.1 操作入口

皇嗣操作固定为：`教育`、`鼓励`、`封爵`、`赏赐`、`问责`。

### 7.2 教育与鼓励

- 教育：选择课程方向、名师、伴读和时间段，写入日程；按日/按学期结算文、武、政治、民生、健康和性格影响。
- 鼓励：即时改变心情、亲近、压力或志向；特定人格可能触发剧情。

### 7.3 封爵

`人物操作页 → 爵位调整 → 选爵位与自定义封号 → 查看封地/礼制影响 → 确认 → 圣旨 → 历史`

- 爵位候选受年龄、继承序列、现有爵位、宗人府礼制约束。
- 可选爵位至少包括贝子、贝勒、郡王、亲王；封号不可与现有有效封号冲突。

### 7.4 赏赐与问责

- 赏赐：御赐墨宝、赏银百两、赏金百两、国库珍宝。
- 问责：严厉呵斥、禁足、削爵、打入宗人府、赐死。
- 禁足改变可前往场景和日程；削爵、宗人府、赐死均需要二次确认并更新继承格局。

## 8. 前朝与公共事务

### 8.0 当前场景核对

场景交互现已建立统一目录，状态分为已开放、部分接入、待开发：太和殿承载重大朝会与册立；乾清门承载日常朝会和朝仪；养心殿承载奏折、召见和休息；军机处承载军情与密折；午门承载朝拜、凯旋和宣示；文华殿承载经筵和皇嗣教育；会同馆承载使团与外交；内务府承载预算和调拨；宗人府承载宗室爵位、婚配和问责；御书房承载读书、国策研究和召见；演武场承载骑射、比武和检阅。

后宫方面，东西六宫的主殿、东西侧殿和庭院共用人物交互；坤宁宫承载皇后、宫务与祭祀；乾清宫承载家宴和宗室事务；交泰殿承载六宫账册与协理六宫；御花园承载游赏、偶遇和季节事件；上书房承载课程、名师和伴读；冷宫承载探视、调查和复位；太医院承载诊脉、安胎和生产；慈宁宫与寿康宫承载长辈事务；御膳房承载传膳和食材事件；撷芳殿承载皇嗣照料、启蒙和指定养母；毓庆宫承载储君培养、监国、封爵和问责。

### 8.1 朝会

`乾清门/太和殿 → 朝会议题 → 臣子发言与辩论 → 皇帝裁决/容后再议 → 结算 → 历史`

- 每日朝会可处理一个重大议题和若干普通议题；玩家可延长朝会。
- 通用回应包含裁决、容后再议、命其他官员或皇子作答、震怒。
- 容后再议的议题次日强制回到议程，直到裁决。

### 8.2 奏折与御书房

`御书房/养心殿 → 奏折列表 → 阅读情报 → 批示/调查/暂缓 → 执行与结算 → 历史`

- 奏折区分紧急度与情报可信度；可信度由呈报者、调查与隐藏信息决定。
- 暂缓可能积累风险、错失时机或产生后续事件。

### 8.3 内务府与国库

- 内务府按预算分账管理，皇帝可调拨；调拨需展示来源、目标、代价和影响。
- 国库物品用于赏赐、任务、修缮和典籍；操作需支持筛选、多选、数量、确认与库存不足反馈。

## 9. 异常与边界规则

- 满编：目标位份、协理六宫席位、官职或爵位无空缺时禁止确认并给出原因。
- 库存不足：国库选择不能超出可用数量；确认时再次校验，避免并发扣减。
- 目标不可操作：死亡、天牢、冷宫、外出、病危、禁足、待审等状态按操作规则禁用。
- 时间冲突：临幸、朝会、教学、召见和旅行等日程冲突时提示玩家改期、取消或覆盖。
- 不可逆操作：赐死、赐自尽、株连九族、抄家落狱须二次确认，确认页明确列出后果。
- 中断：关闭弹窗、返回地图或切换场景不产生状态变化；已进入圣旨用印前仍允许取消。

## 11. 妃嫔行踪与选秀交互补充

### 11.1 有喜通知

`内侍传言 → 大喜/前去关怀/赏赐安胎/暂不声张 → 执行结果 → 关闭通知`

- 大喜：写入皇帝快乐变化并关闭通知。
- 前去关怀：关闭通知，导航到妃嫔固定居所对应的主殿或侧殿。
- 赏赐安胎：关闭通知，打开国库；由后续国库多选完成实际赏赐。
- 暂不声张：关闭通知，不导航、不弹结果、不产生即时动作。

### 11.2 宫女寻人

`进入妃嫔居所但人物不在 → 宫女回禀实际去向 → 罢了/回养心殿/拜驾所在地`

- 罢了：关闭对话，保留当前场景供玩家自行操作。
- 回养心殿：关闭对话并导航养心殿。
- 拜驾所在地：关闭对话并导航人物当前所在场景。
- 人物夜间回宫后不再触发回禀；人物在场时直接显示人物交互入口。
- 点击场景人物头像时，约 30% 概率触发该人物的随机对话，其余情况直接打开人物操作页；人物操作页中的“闲聊”按钮仍固定进入对话，不参与随机判定。

### 11.3 选秀状态机

- `SCHEDULED`：展示开选日期，无候选操作。
- `SELECTING`：逐人选择撂牌子（入选）或赐花（落选），允许在全部决定前改选。
- `AWAITING_ENTRY`：展示入选者与入宫日期，无提前审核。
- `AWAITING_REVIEW`：展示皇后初拟方案，皇帝可修改位份与宫室；缺少宫室或宫室重复时禁止确认。
- `COMPLETED`：写入人物库、关系网、居所与历史，关闭审核弹窗；允许重新筹办下一届。

## 12. 按钮与关闭行为

- 人物操作页继续使用“圆形图标 + 横排两个字”按钮，按钮之间不得重叠。
- 场景交互入口统一使用四字文字按钮，不在文字前放功能图标，例如“妃子列表”“宫中选秀”“召幸翻牌”。
- 选择、赏赐、问责、改位等居中弹窗的关闭键必须独立于滚动内容层，触屏热区至少 44×44 像素，始终位于最上层；点击或触屏按下后立即关闭当前弹窗，不写入任何操作记录。
- 弹窗打开时隐藏场景返回键和同级场景交互按钮，防止关闭键与返回键重叠或误触。

## 13. 养心殿翻牌交互

`养心殿场景 → 召幸翻牌 → 翻牌子原型 → 选中绿头牌 → 确认传召 → 宠幸过场 → 自动关闭 → 登记临幸计划`

- 翻牌界面严格复用 `docs/交互代码/翻牌子.txt` 的布局、分页、选中与确认层，只调整移动端尺寸和动态人物数据。
- 点击关闭或“再想想”：关闭翻牌界面，返回养心殿，不产生任何状态变化。
- 点击“传旨临幸”：关闭翻牌界面，打开既定宠幸动画；动画点击跳过或播放完成后自动关闭。
- 动画关闭时仅登记一次临幸计划，实际怀孕、恩宠和关系变化由次日卯时结算，避免重复点击造成多次结算。
- 翻牌列表为空时显示暂无可召幸妃嫔，并禁用确认按钮；有孕、产后休养、病中、禁足、冷宫、在押和死亡人物不得进入列表。

## 14. 皇嗣婚配交互

`毓庆宫 → 皇子婚配 → 选择成年皇嗣 → 选择路线 → 结果反馈 → 关闭婚配页`

- 无成年可婚配皇嗣：内侍提示后关闭，不打开空白选择页。
- 礼部挑选：四张候选人物条目完整显示“品阶 + 官职 + 嫡庶 + 子/女 + 姓名 + 魅力 + 谋略”；点击候选即确认婚配、更新关系和履历并关闭。
- 婚配大臣：点击无配偶臣子直接完成；点击已有原配臣子显示置顶冲突层，只能“换一位”或“刺死原配”。关闭婚配页不结算。
- 举宴相看：确认后显示具体御花园宴会日期并关闭；十四日后内侍通知提供“前往御花园/稍后前往”，次日回禀提供“同意婚配/不同意”。每个选择结算后关闭当次对话。
- 婚配等待、宴会进行、等待裁决期间，该皇嗣不再出现在其他婚配候选中，防止重复婚配。

## 15. 圣旨用印布局

- 圣旨以透明场景遮罩上的卷轴独立展示，不使用黑色内容框。
- “奉旨用印”固定置于卷轴纸面底部上方，与下方卷轴滚轴保持明确间距；在 320 至 430 像素宽竖屏内不得与滚轴、提示文案或关闭键重叠。
- 点击用印只结算一次；动画完成后自动关闭。右上关闭用于取消未用印圣旨，不产生状态变化。

## 16. 交互队列与场景人物锁定

- 所有自动通知按优先级进入单一队列，每次只显示一条。人物操作页、人物详情、对话、居中选择、国库选择、临幸、圣旨或名单页打开时暂停弹出自动通知。
- 玩家点击人物头像后立即锁定该人物所在场景；直至人物操作链全部关闭或玩家离开场景，日程系统不得随机迁移该人物。
- 随机对话完成或跳过后关闭对话并打开人物操作页。人物操作页关闭后才允许队列继续弹出下一条通知。
- 圣旨用印完成后结算目标状态、写入履历并关闭圣旨，不打开人物详情。取消未用印圣旨不产生状态或履历变化。

## 17. 拘禁与恢复反馈

- 打入冷宫、打入宗人府、抄家落狱：选择确认 → 状态与场景迁移 → 消息反馈 → 关闭弹窗并留在当前场景。被拘人物不得触发普通日程。
- 冷宫操作固定为探望、刺死、恢复；宗人府和牢狱操作固定为探望、赐死、释放。点击任一操作完成结算后关闭当前操作页并给出一次反馈。
- 妃嫔恢复先弹出位份选择；确认后分配合法空置宫室、保留有效封号并写入履历。无可用宫室时禁止确认并提示先腾挪宫室。
- 皇后完成选秀初拟后，内侍通知选项为“前往交泰殿”“稍后再议”。前往直接导航并打开复核界面；稍后只关闭本次通知，复核入口继续保留。
