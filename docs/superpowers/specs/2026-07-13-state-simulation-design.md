# 本地状态与宫廷演算设计

## 目标

将当前 React 原型从局部内存状态升级为可持久化的单机游戏状态。第一阶段只使用 IndexedDB，本地关闭游戏后时间冻结；未来通过替换仓库同步适配器接入账号、云端存档、排行榜和分享。

## 架构

```text
场景 UI / 人物 UI / 国库 UI
          ↓ 读取与派发动作
GameStore（唯一游戏状态）
          ↓
领域服务：时钟、天气、人物、孕育、事件队列、历史
          ↓
SaveRepository（IndexedDB 快照与版本迁移）
```

UI 不直接写 IndexedDB，也不自行修改人物数据。每项操作通过领域动作完成，如 `visitConsort`、`selectEventOption`、`advanceGameTime`。动作返回新的状态与反馈事件，仓库以防抖方式保存。

## 核心数据模型

### GameState

- `version`、`saveId`、`updatedAt`：存档和迁移信息。
- `clock`：年、月、日、日内分钟、暂停和倍速。
- `weather`：日期对应的天气、季节和视觉效果键。
- `people`：以人物 ID 索引的完整人物记录。
- `relationships`：人物关系、亲密、信任、嫉妒、秘密与亲缘。
- `inventory`、`treasury`：物品数量、来源、可赏赐性。
- `events`：待显示、待选择、待结算、已错过的事件队列。
- `history`：操作与自动演算的不可变记录。
- `scenePresence`：人物当前场景、居所、日程、状态。

### PersonRecord

- 基础：ID、姓名、性别、出生年/月/日、年龄、类型、头像/立绘素材键。
- 身份：位份、品阶、官职、爵位、封号、所属派系、居所。
- 六维与扩展：按角色类型使用对应六维，并保留健康、忠诚、野心、宠爱、压力等运算字段。
- 生命周期：`NORMAL`、`PREGNANT`、`SICK`、`REST`、`OUTSIDE`、`CONFINED`、`COLD_PALACE`、`PRISON`、`DEAD`。
- 亲缘：父、母、养母、配偶、子女 ID 列表。

### AssetCatalog

- 人物立绘、头像、场景底图、物品图标均使用稳定逻辑键而不是直接散落的路径。
- 初版提供内置目录；缺失素材使用同类型默认素材并写入开发诊断，不阻塞存档读取。

## 时间、天气与年龄

- 一天约 1.2 分钟；暂停、1 倍、2 倍、4 倍共用一个游戏时钟。
- 游戏关闭时冻结；启动后加载最后快照，不按真实世界时间补算。
- 每过午夜运行日结算；跨月运行月结算；跨年运行年结算。
- 年结算更新所有存活人物年龄，并触发年龄阈值事件，例如皇嗣启蒙、婚配候选与官员致仕提示。
- 天气由北京季节规则和可复现随机种子生成：春季多晴雨，夏季多雨，秋季多晴雾，冬季多晴雪。当天首次生成后存入状态，场景特效只读取该状态。

## 孕育与生育

### 临幸与受孕

1. 临幸过场结束后写入 `VISIT` 历史和当夜访问记录。
2. 次日卯时处理访问：检查妃嫔健康、生育能力、月事/避孕状态、皇帝健康、宠爱、随机种子。
3. 成功受孕时设置 `PREGNANT`、受孕日期、预产日期（十个游戏月后同日；日期不存在时取当月末日）。
4. 生成带选项的内侍传言：大喜、前去关怀、赏赐安胎物、暂不声张。

### 孕期

- 每月结算孕期周数、母体健康、胎儿风险和后宫关系。
- 第三、六、九月可生成体征、安胎、流言或疾病事件；玩家可错过，系统按默认选项结算。
- 妃嫔被打入冷宫、赐死或出现严重疾病时，按规则触发流产、保胎或特殊事件。

### 生育

1. 到达预产期生成高优先级内侍传言。
2. 选项包括前去探望、厚赏六宫、赐名/暂缓赐名、传太医；允许多步处理。
3. 生育结算创建新的皇子或公主人物记录，写入父母与养育关系、健康、出生日期、初始居所。
4. 更新母体健康、宠爱、后宫秩序、国库消耗与历史；产后事件继续进入队列。

## 事件队列与反馈

- 事件字段包括 ID、类型、优先级、创建时间、过期时间、人物 ID、正文、选项、默认选项、状态和结果。
- 优先级：死亡/生产/朝局紧急 > 怀孕/重病 > 任命结果 > 日常消息。
- 普通通知显示“内侍传言”消息框，关闭即标记已读；带选项事件必须选定或到期自动选择默认项。
- 操作完成的结果消息明确显示动作、对象、资源或状态影响；关闭只回到原场景，不撤销已确认结算。

## 数据迁移与错误处理

- 初次加载时从内置演示人物与素材目录生成初始存档。
- 存档带版本号；新增字段使用迁移函数补齐，不删除用户已有数据。
- IndexedDB 不可用时降级为内存模式，并展示一次内侍式提示“存档暂不可用”。
- 保存失败不阻断当前操作，但保留待保存标记并在下次动作重试。

## 测试与验收

- 时钟：暂停不推进；速度倍率正确；日/月/年边界准确；跨年人物年龄加一。
- 天气：同一存档日期可复现；季节规则符合预期；特效键正确。
- 孕育：临幸不直接生子；次日才判定；十月后才触发生产；生产创建亲缘正确的皇嗣。
- 事件：带选项事件只结算一次；到期使用默认选项；关闭结果不回滚。
- 持久化：刷新后人物、时间、库存、孕期与历史保持一致；存档升级不丢字段。
- 场景：人物头像、可用操作和禁用原因与人物状态一致。

## 分期

1. 建立领域模型、初始人物/素材目录、IndexedDB 仓库、存档恢复。
2. 接入时钟、季节天气、年龄、历史与事件队列。
3. 接入临幸、受孕、孕期、生育和内侍传言。
4. 用统一状态替换现有场景和人物 UI 的局部演示状态。
5. 补国库多选、前朝议题和云端同步适配器。
