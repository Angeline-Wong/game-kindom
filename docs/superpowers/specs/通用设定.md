# 紫宸纪通用设定与系统需求

## 文档边界

本文是产品定位、时间天气、角色状态、界面、国库、继承与验收的唯一共享规则来源。前朝专属规则见 [前朝玩法](前朝玩法.md)，后宫和皇嗣专属规则见 [后宫玩法](后宫玩法.md)。

## 产品与核心循环

紫宸纪是竖屏 2.5D 架空清宫帝王成长 H5。玩家以皇帝身份在有限时间内处理朝政、管理后宫、培养继承人；人物拥有独立性格、关系、秘密和日程，事件允许被错过。V1 开放前朝、后宫、国库、更多，京城与巡游暂不展示。

循环为：时间流逝 → 场景与人物变化 → 玩家观察和决策 → 执行者与关系影响结果 → 历史、资源、人物状态更新 → 触发后续事件。

## 时间、天气与移动

一天约 1.2 分钟，时间控制循环为暂停、1 倍、2 倍、4 倍、8 倍，所有日程与事件使用同一游戏时钟。北京四季天气驱动场景光照、环境音、人物路线、健康消耗与事件条件。V1 至少支持晴、雨、雪、雾四类效果，并保证文字、热区、人物操作不被特效遮挡。三年后道具按正常规则完整推演并生成可追溯历史。

一级地图与二级场景均为背景优先；玩家点击地点后自动移动。三级空间返回二级，二级返回一级，禁止越级返回。

## 统一角色与状态

皇帝、官员、妃嫔、皇嗣和重要宫人共享年龄、健康、压力、忠诚、野心、胆识、智慧、魅力、道德、贪欲、嫉妒、城府、家世、财富、声望、人脉和把柄。公开信息、估值信息与完全隐藏信息必须分层。

重要角色统一显示六维雷达图：皇帝为文、武、政治、民生、魅力、健康；官员为智慧、武略、野心、忠诚、派系影响、已知财富；妃嫔为才情、礼仪、容貌、健康、野心、争宠。皇帝精确显示，其余角色按情报显示估值、区间或未知。

人物状态至少包含 `IN_SCENE`、`OUTSIDE`、`EVENT`、`REST`、`SICK`、`LOCK`、`禁足`、`待审`、`冷宫`、`天牢`。人物离场必须显示可知去向，切换场景不能重置位置。

## 人物互动、界面与资源

人物仅在二级及可承载人物的三级场景出现，底部固定头像栏最多四人，按场景主人、剧情人物、皇嗣、高品级、普通人物排序。点击人物头像约有 30% 概率先触发随机对话，其余情况直接进入人物操作页；对话完成或跳过后回到人物操作页，人物姓名名牌才是进入详情的热区。

所有改变资源、职权、位分、居所、自由或关系的操作必须经过：选择目标 → 展示条件、代价与连带影响 → 皇帝确认 / 颁旨 → 场景结果 → 历史记录。禁止浏览器原生弹窗与现代白色卡片。

操作入口统一使用两个字文案。人物姓名名牌是查看详情的唯一热区，不在操作列重复提供“详情”或“查看履历”。对话使用对话选项框；赏赐、问责、迁宫、改位、改品、调任与封爵先使用选择弹窗；仅正式任命、上调位分或上调品阶才进入圣旨展开与用印流程。临幸使用专属帘幕过场，闲聊使用对话选择，不得误走圣旨。

界面使用深木、深红、鎏金和楷体。对话采用场景暗化、人物立绘、正文与选项；降旨采用独立圣旨过渡；人物详情采用场景立绘与右侧纵向操作列。后宫、官员、皇嗣名册共享筛选、搜索、排序、人物卡与底部详情抽屉结构。

## 国库、继承与验收

国库管理可赏赐物品、典籍、药材、材料、任务道具和收藏。赏赐必须从库存选择物品、数量与对象，确认后扣减库存并写入历史。王朝资产、宫殿、工程、人物和世界状态可跨继承保留；皇帝个人能力、压力、私人好感和未记录秘密不直接继承。

关键决策必须幂等，事件结算生成快照与有限恢复记录。性能不足时降低普通 NPC 和动画频率，但不得省略重要人物、仪仗或剧情线索。所有页面在主流竖屏尺寸保证文字与热区不重叠。

## 新档与人物生命周期

- 新档默认拥有皇后一名，不预置皇子或公主；前朝预置一批覆盖中枢、六部、宗人府与禁军的在职臣子。
- 所有人物生日由统一游戏时间驱动，跨过生日自动增加年龄。人物可能因年龄、健康、疾病或意外死亡，死亡写入历史并从可操作名册中移除。
- 在职臣子身故后，其官职形成缺额并由朝廷补授继任者；继任者是独立人物，重新生成年龄、属性、忠诚与关系，不继承前任的个人履历。
- 皇嗣序齿和排行统一使用中文数字，如“一皇子”“二公主”，界面、履历、赐名与宗牒不得混用阿拉伯数字。
## 本轮交互补充

- 皇子操作固定为教育、鼓励、封爵、赏赐、问责。封爵使用爵位调整界面，并允许输入自定义封号；问责包括严厉呵斥、禁足、削爵、打入宗人府、赐死。
- 场景底部人物入口统一采用人物头像组件；人物名牌打开详情。详情根据妃嫔、大臣、皇子分别展示对应身份、地点、核心数值与专长，不复用固定妃嫔文案。

## 人物调度、事件互斥与姓名唯一性

- 玩家已在当前场景看到某人物头像时，该人物在离开场景或关闭人物交互前锁定于当前场景，实时日程不得在玩家眼前将其随机迁走。
- 人物随机对话、内侍通知、人物操作页、人物详情、选择弹窗、临幸和圣旨均进入统一交互队列。同一时刻只展示一个交互；人物操作、详情或具体选择尚未关闭时，不弹出下一条对话或通知。
- 正式晋升、改品、调任、封爵和赐名完成圣旨动画后，关闭圣旨并回到当前场景，不自动打开人物详情。
- 妃嫔、臣子、皇嗣分别拥有至少 500 个不重复候选姓名。本朝一经使用即写入已用名册；选秀落选、人物死亡、革职或离宫均不释放姓名，后续生成不得复用。新朝可按继承规则重新建立姓名占用表。
