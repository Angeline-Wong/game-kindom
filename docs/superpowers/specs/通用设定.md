# 紫宸纪通用设定与系统需求

## 文档边界

本文是产品定位、时间天气、角色状态、界面、国库、继承与验收的唯一共享规则来源。前朝专属规则见 [前朝玩法](前朝玩法.md)，后宫和皇嗣专属规则见 [后宫玩法](后宫玩法.md)。

## 产品与核心循环

紫宸纪是竖屏 2.5D 架空清宫帝王成长 H5。玩家以皇帝身份在有限时间内处理朝政、管理后宫、培养继承人；人物拥有独立性格、关系、秘密和日程，事件允许被错过。V1 开放前朝、后宫、国库、更多，京城与巡游暂不展示。

循环为：时间流逝 → 场景与人物变化 → 玩家观察和决策 → 执行者与关系影响结果 → 历史、资源、人物状态更新 → 触发后续事件。

## 时间、天气与移动

一天约 1.2 分钟，时间控制循环为暂停、1 倍、2 倍、4 倍，所有日程与事件使用同一游戏时钟。北京四季天气驱动场景光照、环境音、人物路线、健康消耗与事件条件。V1 至少支持晴、雨、雪、雾四类效果，并保证文字、热区、人物操作不被特效遮挡。三年后道具按正常规则完整推演并生成可追溯历史。

一级地图与二级场景均为背景优先；玩家点击地点后自动移动。三级空间返回二级，二级返回一级，禁止越级返回。

## 统一角色与状态

皇帝、官员、妃嫔、皇嗣和重要宫人共享年龄、健康、压力、忠诚、野心、胆识、智慧、魅力、道德、贪欲、嫉妒、城府、家世、财富、声望、人脉和把柄。公开信息、估值信息与完全隐藏信息必须分层。

重要角色统一显示六维雷达图：皇帝为文、武、政治、民生、魅力、健康；官员为智慧、武略、野心、忠诚、派系影响、已知财富；妃嫔为才情、礼仪、容貌、健康、野心、争宠。皇帝精确显示，其余角色按情报显示估值、区间或未知。

人物状态至少包含 `IN_SCENE`、`OUTSIDE`、`EVENT`、`REST`、`SICK`、`LOCK`、`禁足`、`待审`、`冷宫`、`天牢`。人物离场必须显示可知去向，切换场景不能重置位置。

## 人物互动、界面与资源

人物仅在二级及可承载人物的三级场景出现，底部固定头像栏最多四人，按场景主人、剧情人物、皇嗣、高品级、普通人物排序。点击人物先判定对话；必经对话完成后进入详情。

所有改变资源、职权、位分、居所、自由或关系的操作必须经过：选择目标 → 展示条件、代价与连带影响 → 皇帝确认 / 颁旨 → 场景结果 → 历史记录。禁止浏览器原生弹窗与现代白色卡片。

界面使用深木、深红、鎏金和楷体。对话采用场景暗化、人物立绘、正文与选项；降旨采用独立圣旨过渡；人物详情采用场景立绘与右侧纵向操作列。后宫、官员、皇嗣名册共享筛选、搜索、排序、人物卡与底部详情抽屉结构。

## 国库、继承与验收

国库管理可赏赐物品、典籍、药材、材料、任务道具和收藏。赏赐必须从库存选择物品、数量与对象，确认后扣减库存并写入历史。王朝资产、宫殿、工程、人物和世界状态可跨继承保留；皇帝个人能力、压力、私人好感和未记录秘密不直接继承。

关键决策必须幂等，事件结算生成快照与有限恢复记录。性能不足时降低普通 NPC 和动画频率，但不得省略重要人物、仪仗或剧情线索。所有页面在主流竖屏尺寸保证文字与热区不重叠。
