# 人物互动系统需求文档（V1.0）

## 一、需求概述

为增强游戏沉浸感，在**前朝**与**后宫**所有二级场景中增加人物互动系统。

玩家进入二级场景后，可以遇见场景人物，与人物进行对话、查看详情，并执行人物管理操作。

整个系统采用统一交互流程，所有人物（大臣、皇子、妃子等）均遵循同一套逻辑，仅人物详情及可执行操作不同。

---

# 二、整体交互流程

统一流程如下：

```text
进入二级场景
      │
      ▼
加载当前场景人物
      │
      ▼
展示人物头像
      │
      ▼
点击人物
      │
      ▼
判断是否触发对话
      │
 ┌────┴────┐
 │         │
 ▼         ▼
进入对话   直接进入详情
 │
 ▼
完成全部对话
 │
 ▼
进入人物详情
 │
 ▼
执行人物操作
 │
 ▼
返回当前二级场景
```

> **原则：**
>
> * 对话不是必定发生。
> * 如果存在可触发对话，则必须先完成对话，再进入人物详情。
> * 如果没有可触发对话，则直接进入人物详情。

# 五、人物头像展示规范

## 5.1 展示位置

人物统一显示在页面底部。

例如：

```text
────────────────────

       当前场景背景

────────────────────

□    □    □    □

────────────────────
```

人物头像固定排列，不跟随背景物件摆放。

---

## 5.2 头像框

统一采用：

* 正方形头像框
* 固定尺寸
* 古风边框
* 所有人物一致

推荐：

```text
96 × 96
```

统一配置：

```json
{
  "shape":"square",
  "width":96,
  "height":96,
  "gap":16,
  "maxVisibleCount":4
}
```

头像超出部分裁切。

不能改变头像框大小。

---

## 5.3 排列方式

统一：

从左到右排列。

例如：

```text
□  □  □  □
```

禁止：

* 散落摆放
* 根据背景位置变化
* 大小不一致

---

## 5.4 排序优先级

按照以下顺序排序：

1. 当前场景主人
2. 当前剧情人物
3. 皇嗣
4. 高品级人物
5. 普通人物

同级按照配置排序。

---

## 5.5 最大显示数量

默认：

```text

```

例如：

```text

```

超过：

```text

```

点击"更多"弹出人物列表。

# 七、人物对话系统

## 7.1 对话原则

人物对话属于随机事件。

不是每次点击都会发生。

每个人物拥有：

```text
dialogChance
```

例如：

```text
30%
```

表示：

30%进入剧情。

70%直接进入详情。

---

## 7.2 后续影响因素

可由：

* 节日
* 心情
* 好感
* 圣宠
* 皇帝行为
* 最近事件
* 人物关系

共同决定是否进入剧情。

---

## 7.3 对话界面

背景：

保持当前二级场景背景。

例如：

```text
文华殿

↓

点击大臣

↓

背景仍然是文华殿
```

展示：

* 人物立绘
* 对话内容
* 玩家选项

例如：

```text
皇上，

近日边关军情……

①立即处理

②再观察

③交由兵部
```

---

## 7.4 对话结束

完成所有选择后：

自动进入人物详情。

无需再次点击人物。

# 十五、开发原则

1. **统一交互**：所有人物（大臣、皇子、妃子）使用同一套交互流程，仅详情页和操作按钮不同。
2. **背景保持一致**：人物对话和详情均使用当前二级场景背景，不切换独立页面。
3. **对话优先**：存在可触发对话时，必须先完成对话，再进入人物详情；无对话时直接进入详情。
4. **位置连续**：人物位置在同一时间段内保持一致，不因切换场景重新随机。
5. **统一展示**：所有人物均以固定尺寸的方形头像框展示，按优先级从左至右排列，最多显示4人，超出使用“更多”入口。
6. **数据驱动**：人物位置、状态、对话触发、操作权限、排序优先级等全部通过配置控制，便于后续扩展大量人物、剧情和随机事件，无需修改交互逻辑。

我看了你的原始需求文档，实际上里面已经把**前朝官职体系、九品十八级、六部、内阁、军机处、后宫位分、主位制度、摄六宫事、国库/私库、赏赐体系**等都设计好了。

目前 AI 已经完成了：

> **进入二级场景 → 点击人物 → （随机）人物对话 → 人物详情**

实际上只完成了整个人物系统的 **30%**。

对应居住规则：

* **主殿**：仅居住本宫主位（嫔位及以上，或临时主位）。
* **东配殿**：通常居住一名低位妃嫔（贵人、常在、答应）。
* **西配殿**：通常居住一名低位妃嫔。
* **后殿**：侍从、宫务、会客、储物等功能，不作为普通妃嫔常驻居所。
* **庭院**：人物随机活动、偶遇、散步、宫斗事件触发区域。

这样整个游戏的空间层级就会变成：

> **一级地图（后宫） → 二级宫殿（翊坤宫） → 三级建筑（主殿/东配殿/西配殿/后殿/庭院） → 人物互动**

这与你最初的世界观设计保持一致，也为后续宫斗、偷听、拜访、调查、怀孕、生育等玩法预留了完整的扩展空间。
