# 紫宸纪事本地打包

## 双击打包 Web 版本

双击 tools/package.bat。完成后会在 release 目录生成带时间戳的 Web 压缩包。

## 命令行用法

在项目根目录打开 PowerShell：

    ./tools/package.ps1 -Target web
    ./tools/package.ps1 -Target android
    ./tools/package.ps1 -Target all

-Target web 生成可部署的前端压缩包；-Target android 生成 Android Debug APK；-Target all 同时生成两种产物。

默认会执行 TypeScript 检查和前端构建；自动化测试是可选步骤，需要明确加上 -RunTests：

    ./tools/package.ps1 -Target web -RunTests

首次使用或依赖需要更新时加 -InstallDependencies，脚本会执行 npm ci。

Android 打包需要 JDK 17+；Android Gradle Wrapper 会自动处理 Gradle 版本，Android SDK 需要按 Capacitor/Android Studio 的要求安装并配置。
